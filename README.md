# 图的m着色问题 - 多种算法实现

本项目使用C++实现了图的m着色问题的10种不同算法。

## 算法列表

| 算法      | 文件                     | 类型    | 特点              |
| ------- | ---------------------- | ----- | --------------- |
| 回溯算法    | `backtracking.h`       | 精确算法  | 深度优先搜索，保证找到最优解  |
| 贪心算法    | `greedy.h`             | 近似算法  | 快速高效，不保证最优解     |
| 分支限界算法  | `branchandbound.h`     | 精确算法  | 广度优先搜索，使用界限函数剪枝 |
| 遗传算法    | `genetic.h`            | 启发式算法 | 模拟生物进化，全局搜索能力强  |
| 模拟退火算法  | `simulatedannealing.h` | 启发式算法 | 能跳出局部最优解        |
| 膜进化算法   | `membraneevolution.h`  | 启发式算法 | 基于膜计算的进化算法      |
| 禁忌搜索算法  | `taboosearch.h`        | 启发式算法 | 使用禁忌表避免重复搜索     |
| 蚁群算法    | `antcolony.h`          | 启发式算法 | 模拟蚂蚁觅食行为        |
| 粒子群优化算法 | `pso.h`                | 启发式算法 | 模拟鸟群觅食行为        |

## 算法详解

### 1. 回溯算法

- **原理**: 使用深度优先搜索遍历解空间树，尝试为每个顶点分配颜色
- **时间复杂度**: O(m^V)，其中m是颜色数，V是顶点数
- **优点**: 保证找到最优解（如果存在）
- **缺点**: 对于大规模图，时间开销极大

### 2. 贪心算法

- **原理**: 按顺序为顶点着色，每次选择可用的最小颜色编号
- **时间复杂度**: O(m × V)
- **优点**: 简单高效，适合大规模图
- **缺点**: 不能保证最优解，结果取决于顶点处理顺序

### 3. 分支限界算法

- **原理**: 使用广度优先搜索，利用界限函数剪枝
- **时间复杂度**: 最坏O(m^V)，实际通常优于回溯
- **优点**: 可以找到最优解，剪枝效率高
- **缺点**: 空间开销大，需要存储大量节点

### 4. 遗传算法

- **原理**: 模拟生物进化，通过选择、交叉、变异操作优化种群
- **参数**: 种群大小、进化代数、变异率
- **优点**: 全局搜索能力强，适应性好
- **缺点**: 参数设置影响性能，收敛速度可能较慢

### 5. 模拟退火算法

- **原理**: 模拟物理退火过程，以一定概率接受劣解
- **参数**: 初始温度、冷却率、最大迭代次数
- **优点**: 能跳出局部最优，探索能力强
- **缺点**: 参数敏感，需要多次实验调参

### 6. 膜进化算法

- **原理**: 基于膜计算框架，使用复制、融合、分裂、溶解等算子
- **操作**: 融合、分裂、溶解、局部搜索
- **优点**: 结合多种进化策略，搜索能力强
- **缺点**: 实现复杂，参数较多

### 7. 禁忌搜索算法

- **原理**: 使用禁忌表记录最近访问的解，避免重复搜索
- **参数**: 禁忌表长度、最大迭代次数
- **优点**: 避免陷入局部最优，实现简单
- **缺点**: 禁忌表大小影响性能

### 8. 蚁群算法

- **原理**: 模拟蚂蚁信息素释放和跟随行为
- **参数**: 蚂蚁数量、迭代次数、信息素重要程度、启发式信息重要程度、蒸发系数
- **优点**: 全局搜索能力强，自适应性
- **缺点**: 初期收敛慢，参数敏感

### 9. 粒子群优化算法

- **原理**: 模拟鸟群觅食的信息共享和协作行为
- **参数**: 粒子数量、迭代次数、惯性权重、学习因子
- **优点**: 收敛速度快，实现简单
- **缺点**: 容易陷入局部最优
